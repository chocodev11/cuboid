# Assets

Source art, fonts, sounds and data tables that the `cuboid-assets` crate embeds with `include_bytes!`.
Nothing here is downloaded at build or start-up time.

## Policy

- Own art and sounds are created for this project and released under CC0. They imitate the sizes,
  borders and roles listed in the specifications (ui 13, 15), never the pixels of the original.
- Open Sans (Regular, Bold, Italic) is shipped under the SIL Open Font Licence 1.1; its licence text
  travels with the notices generated by `cargo about`.
- Data tables (legacy Minecraft ids, palettes) are factual and regenerated from public data; their
  provenance follows the owner's decision on interop 33.3.
- No asset, scene data, logo or code of Cubik Studio and nothing from Blockbench (GPL-3.0) may be
  added. Pictures of a user's own Cubik installation are only ever read at run time, as an optional
  local skin pack, and are never copied here.

## Layout

| Folder | Content | Work package |
|---|---|---|
| `ui/frames/` | frame and 9-slice pictures | W5.2 |
| `ui/icons/`, `ui/cursors/` | icon and cursor inventories (ui 15.2) | W5.7 |
| `sounds/` | the menu sound set (menus 8.3) | W5.7 |
| `preview/` | display preview scenes (app 9.5) | W3.7 |
| `data/` | tables and palettes | W4.8 |
