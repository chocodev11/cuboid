# Assets

The files the app embeds live in the `cuboid-assets` crate and are embedded with `include_bytes!`.
Nothing is downloaded at build or start-up time.

| Folder | Content |
|---|---|
| `crates/cuboid-assets/fonts/inter/` | Inter Regular, Medium and SemiBold (SIL Open Font Licence 1.1) |
| `crates/cuboid-assets/icons/phosphor/` | Phosphor Icons Regular as an icon font (MIT) |
| `crates/cuboid-assets/data/` | factual data tables, such as the Minecraft version table |
| `crates/cuboid-assets/brand/` | the logo: SVG masters per size band; PNG and ICO renders from `cargo xtask brand` (`docs/design/logo.md`) |

Sources, versions and checksums of the third-party files are listed in
`crates/cuboid-assets/THIRD_PARTY.md`; their licence texts travel with the notices generated by
`cargo about`.

## Policy

- Own art and sounds are created for this project and released under CC0. The logo's terms are decided
  separately (`docs/design/logo.md`, D-L2).
- Data tables are factual and regenerated from public data, with their source named in the table.
- No asset, scene data, logo or code of Cubik Studio and nothing from Blockbench (GPL-3.0) may be
  added. Pictures of a user's own Cubik installation are only ever read at run time and are never
  copied here.
