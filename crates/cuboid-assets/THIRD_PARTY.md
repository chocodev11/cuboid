# Third-party assets

Two families of files are copied into this crate. Both were downloaded once, by hand, from the official
source below, checked against the checksum the publisher lists where there is one, and are embedded
with `include_bytes!`. Nothing is downloaded at build or run time.

The codepoint map `src/phosphor_map.rs` is generated by `icons/phosphor/gen_map.py` from
`package/src/regular/style.css` of the same archive (SHA-256
`873761b8711147dc516b6102936e9ad005f3a3015349efcde1a496f0326f1051`). To refresh it after a version
bump, unpack that one file into an empty folder and run, from another empty folder,
`python -I gen_map.py <style.css> <phosphor_map.rs>`.
